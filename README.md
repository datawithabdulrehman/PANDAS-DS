# 🐼 Pandas for Data Science (PANDAS-DS)

Welcome to my Pandas repository! This project contains a structured, step-by-step guide and practical implementations of data manipulation, cleaning, and analysis techniques using the Python **Pandas** library. It is designed to build a rock-solid foundation for Data Science and Analytics workflows.

## 🛠️ Tech Stack & Prerequisites
* **Python 3.x**
* **Pandas** (Core Data Manipulation)
* **NumPy** (Mathematical Foundations)
* **Jupyter Notebook / JupyterLab**

---

## 📂 Repository Structure & Notebooks

Here is a breakdown of the core topics and source files covered in this repository:

### 1. 📋 Data Structures & Selection
* **`1)Series.ipynb`**: Understanding 1D labeled arrays (Pandas Series), indexing, and vector operations.
* **`2)DataFrames.ipynb`**: Creating, indexing, slicing, and selecting rows/columns in 2D tabular DataFrames.

### 2. 🧼 Data Cleaning & Operations
* **`3)MissingData.ipynb`**: Strategies to handle null or missing values using detection, dropping (`dropna`), and filling (`fillna`) methods.
* **`7)Operations.ipynb`**: Applying custom functions, finding unique values, sorting, and conditional filtering on datasets.

### 3. 🔄 Data Aggregation & Reshaping
* **`4)MergingJoiningConcatination.ipynb`**: Combining multiple DataFrames logically using SQL-like joins, merges, and concatenations.
* **`5)GroupByAggregation.ipynb`**: Grouping data based on categories and applying mathematical aggregate operations (sum, mean, count).
* **`6)PivotTables.ipynb`**: Creating multi-index summaries and pivoting data tables for deep insights.

### 📊 Included Datasets
* **`Countries.csv`**: Used for global demographic and geographic data handling.
* **`anime.csv`**: Used for practicing text filtering, sorting, categorical analysis, and multi-index aggregation queries.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd PANDAS-DS
   ```
3. **Install Pandas & NumPy (if not already installed):**
   ```bash
   pip install pandas numpy
   ```
4. **Launch your notebook environment:**
   ```bash
   jupyter lab
   ```
